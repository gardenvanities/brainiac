# Diário de Desenvolvimento — BRAINIAC

## Decisão: Adotar TypeScript 7.0.2

**Contexto:** template inicial trouxe `^5.6.2`; optei pela v7.0.2 (a mais recente).

**Motivação:** performance (~10x mais rápido em Go), modernidade (projeto novo, base pequena) e ecossistema compatível (Svelte, Vite, Tauri).

**Riscos e mitigações:** breaking changes (acompanhar release notes), incompatibilidade com ferramentas (validar com Biome e builds), novos erros de tipo (ajustar interfaces/casts) e estabilidade geral (monitorar comportamento).

**Reflexão:** projeto pequeno → risco controlado. A performance extra compensa possíveis ajustes iniciais.
